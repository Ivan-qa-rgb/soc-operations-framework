# SOC Operations Framework

Учебный репозиторий для практики SOC: кейсы полного цикла, детекты, runbooks,
автоматизация и тесты.

Все имена, домены, IP-адреса, хэши, пользователи и события — синтетические.
Репозиторий не содержит реальных индикаторов компрометации и предназначен
для обучения.

## Структура

```text
cases/        Учебные инциденты полного цикла
docs/         Политики и методические материалы
detections/   Переиспользуемые детекты
playbooks/    Процедуры реагирования
automation/   Скрипты автоматизации
integrations/ Примеры интеграций
tests/        Проверки данных, детектов и инструментов
```

## Учебные кейсы

- [Case 2025-014 — Ночной инцидент в финтех-стартапе](cases/case-2025-014-night-incident/README.md)

Полный цикл: LSASS access → session/token revocation → suspected transaction
data exfiltration → IR → PIR → new detections.

## Как использовать

1. Выберите кейс в `cases/`.
2. Прочитайте `00-brief.md`.
3. Работайте с алертами и телеметрией самостоятельно.
4. Заполняйте шаблоны triage, investigation и response.
5. Только после собственных выводов открывайте `solutions/`.

## Безопасность репозитория

- Не коммитьте токены, ключи, пароли, cookies, реальные IP и личные данные.
- Используйте `.gitignore`.
- Включите GitHub Secret Scanning и Push Protection.
- Все учебные данные должны быть синтетическими.
